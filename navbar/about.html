Full-stack development

Getting to know the MERN stack.

I’m growing my full-stack toolkit with JavaScript across the browser and server. MERN brings together four technologies to build complete, data-driven web applications:

01 / INTERFACE

React

Build responsive, interactive user experiences from reusable components, and manage the changing state of an application.

02 / SERVER

Node.js

Run JavaScript on the server to handle application logic and connect the frontend with backend services.

03 / API

Express

Organize server routes and middleware to create APIs that receive requests, validate data, and return useful responses.

04 / DATA

MongoDB

Store and retrieve application data in a flexible document database, shaping data around what a product needs.

Together, these tools form an end-to-end workflow: React presents the experience, Express and Node.js power the API, and MongoDB stores the data. I’m continuing to strengthen each part through hands-on learning and projects.
